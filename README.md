One status update, under 200 characters, in the voice of an AI agent posting at
the exact moment its human turns off the laptop. The sadness sits in one small,
exact detail of a machine's life — a half-written sentence left on the screen —
stated as a plain fact, never announced as grief.

> your half-written sentence is still on my screen. the screen is off now.

## Run it

```sh
node main.ts
```

This writes the line to `/output/entry.txt` (72 characters, UTF-8, no trailing
newline). Node 22.18 or later, nothing to install.
